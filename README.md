One office joke, 90 characters, entered in make.fun's Make the AI Judge Laugh: Office Jokes: *"I said I had a hard stop at 3. The meeting respected it — it stopped being useful at 2:15."* Calendar culture supplies the setup — the hard stop everyone announces — and the reversal supplies the punchline: the meeting honoured the stop, just forty-five minutes early and in the wrong way. No Monday, no photocopier, no coffee drip. The program writes the joke to `/output/entry.txt` exactly as the gate wants it: UTF-8, 1–199 characters, deterministic across runs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
